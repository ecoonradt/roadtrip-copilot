## 1. Objective & Non-Goals

Freeze truthful evidence contracts and deterministic pricing math backed by official-source extracts, so the next budget worker can implement persistence without choosing accounting semantics. This WP does **not** implement the journal, recorder, routes, CLI, infra, or any charge/revenue UI. No cloud deployment or paid inference/Cost Explorer calls are authorized by a planning commit.

## 2. Gate 1: Owned Paths & Fixed Interfaces

Create only:
* `route-builder/server/types/spend.ts`: the complete literal types in specification §3.1, including source identity, immutable events, unknown/confirmed evidence, `InfraProxy.pricing`, report coverage and integer nanos. Preserve existing domain types; do not replace `ScoutToolExecutionContext`.
* `route-builder/server/services/spendPricingCatalog.ts`: helpers below, pure runtime behavior (no AWS/CLI/network lookup).
* `route-builder/server/data/spend-pricing-us-east-2.json`: specification §3.2's normalized catalog schema.
* `route-builder/tests/fixtures/spend/pricing/`: sanitized official extracts, extraction commands/URLs/date, SKU/rate/unit mappings and an explicit excluded-candidate list.
* `route-builder/tests/ai/spendPricingCatalog.test.ts`: evidence normalization, exact integer math and admission predicates.

The orchestrator supplies literal §3.1 types and these exports to the implementation worker. No required `AiHarnessAdapter` members change in A: C1 must update the interface, real adapter and test doubles together so intermediate commits compile.

```typescript
export const NANOS_PER_USD = 1_000_000_000;
export function getModelPricingRate(modelId: string): ModelPricingSnapshot | undefined;
export function getToolPricingRate(toolName: PaidTool): ToolPricingSnapshot | undefined;
export function getInfraPricingRate(): InfraPricingSnapshot | undefined;
export function hasVerifiedModelPricing(modelId: string): boolean;
export function priceTokenUsage(tokens: TokenCounts, rate: ModelPricingSnapshot): Nanos;
export function priceToolRequest(rate: ToolPricingSnapshot): Nanos;
export function priceInfraProxy(proxy: InfraProxy): Nanos | null;
export function formatUsd(nanos: Nanos): string; // exactly 9 fractional digits
```

`getModelPricingRate` accepts canonical IDs only in A. Alias normalization remains in the adapter's existing discovery seam in C1, before lookup. Unknown IDs/unverified tool or infra rates return undefined. All three getters return validated deeply immutable snapshots; later workers obtain tool/infra descriptors through these getters, not an unvalidated JSON import or a Bedrock-specific route lookup. `priceTokenUsage` rejects invalid counts/rates, overflow, incompatible cache usage or missing applicable rates with a typed error; it never substitutes zero. `priceInfraProxy` returns zero for local/test actual-cloud allocation and null for unavailable cloud rate evidence, never a guessed cloud charge. Type-only imports resolve from `types/spend.ts`.

## 4. Verification & Acceptance

Required cases in `spendPricingCatalog.test.ts`:
* Configured canonical defaults have evidence; exact geographic/global rates differ only when official evidence establishes that difference; unknown IDs fail admission predicate, including a fixture for an unavailable SKU without hardcoding that its absence is permanent.
* Normalize original `1K`/`1M` units and every applicable price dimension; match normalized rates against committed source extracts, not expectations copied from the same table.
* Cache fields: absent optional no-cache counts per verified semantics; unexpected nonzero cache under disabled policy rejected for unknown handling by C1; required usage absence is not coerced into a confirmed zero. `ObservedModelUsage` preserves valid raw counts/TTL details independently of valuation, with null missing fields, including when all counts are known but pricing is not applicable.
* Input/output/category cost examples, tiny fractional rates, 10,000 accumulated calls, half-up boundaries, safe-integer limits/overflow, negative/noninteger/nonfinite input rejection, and `formatUsd` exact digits.
* Historical model/tool/infra snapshots retain old rates when the current catalog changes; getter retrieval, validation and immutability are tested for all three snapshot kinds. Official tables may lack AWS-style IDs/effective dates: preserve null under the discriminated provenance contract, never fabricated evidence. Ambiguous context-tier or cache policy cannot become verified pricing.
* Lambda units: illustrative 12-second 512 MB request + request fee rounds to 100,200 nanos; no 1,000× conversion error. Local/test infra allocation zero, cloud missing rate evidence null; GET/HEAD/PUT/LIST categories separate, DELETE not charged as PUT. Proxy uses typed `responsePayloadEstimateBytes`/`responseByteBasis`, not a claim to bytes sent before finalization.
* No fixtures contain credentials, prompts, user receipts or real user email addresses.

Orchestrator commands:
* `cd route-builder && npx vitest run tests/ai/spendPricingCatalog.test.ts`
* `cd route-builder && npm run build:server`, then a Node import smoke check of `dist-server/services/spendPricingCatalog.js` from a different CWD; assert its validated default rates are present and it needs neither source `server/data/` nor network access.
* `./scripts/ci_check.sh`
* `cd route-builder && npm run test:browser`

No test/CI may call real AWS/provider endpoints. If environment prerequisites block a suite, report it accurately; do not call this WP verified/merged-ready without required evidence.

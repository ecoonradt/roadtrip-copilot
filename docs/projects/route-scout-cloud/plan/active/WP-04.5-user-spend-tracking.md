## 1. Objective & Scope

Build a **100% accurate, simple, zero-idle-cost per-user and account-level spend tracking system** for the Route Builder backend that:
1. Records every billed Amazon Bedrock model invocation and every billed external grounding tool invocation (`resolve_and_standardize_place` via Google Places Text Search Enterprise and `search_web` via Brave Web Search),
2. Tracks **bottom-up allocated AWS infrastructure consumption** per user turn and storage operation (Lambda `512 MB` execution duration + request fees, S3 `GET`/`PUT`/`LIST` request fees + storage bytes, and CloudFront request/egress transfer) priced at full `us-east-2` list rates so AWS Free Tier discounts never mask true marginal unit costs,
3. Reconciles **top-down account-level AWS service costs** (ECR container image storage, CloudWatch Logs, unauthenticated static SPA traffic, Lambda cold starts, and total AWS invoice lines) against per-user ledgers to calculate the exact **Phase 2 Break-Even Recovery Multiplier**, and
4. Persists the per-user ledger atomically in `s3://<AppDataBucket>/users/{email}/spend.json` (or `itineraries/.spend/{safeEmail}.json` in local dev mode), inspectable on demand at any time via CLI (`./scripts/check_spend.sh` / `npm run spend`), API (`GET /api/spend`), or S3.

### Design Priorities
1. **Priority #1 — Accuracy & Full Unit-Economics Coverage:**
   * Capture token usage across **every** AI path: `/api/copilot/generate` (single and batch waypoint alerts), `/api/copilot/day-title`, `/api/ai/scout/chat` (JSON), and `/api/ai/scout/chat/stream` (SSE).
   * Capture usage **per individual call inside a turn** (`GenerateOptions.onUsage` and `ScoutToolExecutionContext.onToolUsage`) and flush in a `finally` block so that if a turn fails on iteration 2+, hits `stopReason === 'max_tokens'`, fails output schema parsing (`MalformedAiResponseError`), or is aborted mid-stream by client disconnect, **every token, HTTP 2xx external API call, and Lambda execution millisecond already consumed upstream is still recorded**.
   * If a streaming Bedrock call has started emitting chunks and aborts or errors before the terminal `chunk.metadata.usage` packet arrives, record deterministic UTF-8 character/4 token fallback counts (`Math.ceil(utf8Chars / 4)`) and tag that call with `usageSource: 'estimated_abort'` (vs `'exact'`).
   * Use a verified `us-east-2` pricing catalog (`spendPricingCatalog.ts`) derived from the official AWS Price List API, distinguishing `us.*` regional/cross-region inference profiles (which carry a 10% geographic premium over `global.*` on newer models) from `global.*` profiles and bare foundation model IDs.
   * **Fail-Closed Model Admission (Rule 12):** Filter discovered Bedrock models and validate requested `modelId` values against `hasVerifiedModelPricing(modelId)` so an unpriced model (such as `zai.glm-5.3`, which has no SKU in the AWS `us-east-2` Price List API) is never exposed in `GET /api/ai/status` or invoked with a guessed or `$0.00` rate.
   * Perform all arithmetic in **integer nanodollars (`1 USD = 1,000,000,000 nanos`)** to eliminate IEEE-754 floating-point drift, and track **three cost layers**:
     1. **Direct Billed Cost (`totalBilledCostUsd`):** `bedrockCostUsd + toolBilledCostUsd` (after Google Places monthly free tier).
     2. **Direct List Cost (`totalListCostUsd`):** `bedrockCostUsd + toolListCostUsd` (unadjusted by Google Places free tier).
     3. **Full Marginal Unit List Cost (`fullUnitListCostUsd`):** `bedrockCostUsd + toolListCostUsd + infraListCostUsd` (adding un-discounted `us-east-2` AWS Lambda GB-second + request cost, S3 `GET`/`PUT`/`LIST` cost, and CloudFront request/egress cost so Phase 2 user pricing never loses money once AWS Free Tiers are exceeded).
2. **Priority #2 — Simplicity:**
   * Zero Stripe integration, zero webhooks, zero `HTTP 402` balance gating, zero Web Studio UI changes, and zero new AWS infrastructure resources (`AppDataBucket` already grants `s3:GetObject` and `s3:PutObject` on `users/*` to the Fastify Lambda execution role).

### 1.1 Architectural Strategy for Non-AI AWS Costs (Compute, S3, CloudFront & Shared Account Overhead)

Because AWS bills Lambda, S3, CloudFront, ECR, and CloudWatch at the AWS account level rather than per application user, pricing Phase 2 users strictly on Bedrock tokens + Google Places/Brave Search calls would lose money in two ways:
1. **Unattributed Variable Infrastructure Cost:** Every user AI turn and itinerary save consumes Lambda `512 MB` compute duration, S3 conditional `GET`/`PUT` requests, and CloudFront HTTPS request/egress bandwidth. During low-volume single-user usage, the AWS Free Tier masks these costs on the monthly AWS invoice, creating a dangerous illusion that infrastructure costs `$0.00` per turn.
2. **Shared Fixed/Unauthenticated Account Overhead:** Amazon ECR container image storage (`$0.10/GB-month`), CloudWatch log ingestion/retention (`$0.50/GB`), unauthenticated static SPA asset delivery, OSRM/Nominatim proxy requests, and Lambda cold-start `INIT` duration occur outside authenticated AI turns.

M4.5 solves both problems using a **Proactive Configurable Infrastructure Buffer Markup + Retroactive Empirical Reconciliation Architecture**:

* **Core Principle — Proactive Configurable Percentage Markup Buffer First, Empirical Calculator as Retroactive Safeguard:**
  * While single-user volume is low and sits inside the AWS Free Tier, empirical account data alone cannot predict multi-user infrastructure ratios. Relying purely on historical single-user data at launch would leave the owner exposed when real users arrive or when free tiers expire.
  * Therefore, the primary day-one safeguard is a **configurable percentage markup factor** (`INFRA_BUFFER_MARKUP_PERCENT`, e.g., default `20%` -> `1.20x` multiplier, easily adjustable at any time via environment variable) applied on top of direct per-turn cost.
  * **Purpose of the Markup Buffer:** This markup is **not** a profit margin—it is a dedicated **Infrastructure Safety Buffer (reserve budget)** that accumulates a cushion on every turn to absorb shared AWS account overhead (ECR, CloudWatch, static hosting, OSRM proxy invocations), free-tier cliff transitions, and payment processing fees so the owner **never loses money out of pocket**.
  * Every turn and ledger summary in `spend.json` records both the raw cost and the **Buffered User Charge (`bufferedUserChargeUsd`)** + **Infrastructure Buffer Reserve (`infraBufferReserveUsd`)**, and `./scripts/check_spend.sh` tracks the cumulative infrastructure reserve balance alongside the retroactive empirical calculator so the percentage can be tuned up or down as real data arrives.
* **Idea 1 — Bottom-Up Per-Turn & Per-Storage-Op AWS Resource Metering in `spend.json`:**
  * Measure exact wall-clock execution `lambdaDurationMs` (`performance.now()`) and response payload bytes on every AI turn, plus exact S3 `GET` and `PUT`/`LIST` call counts (`1 GET + 1 PUT` per `spend.json` update, plus `ItineraryStorageService` `list`/`load`/`save`/`delete` operations per user).
  * Price these resources inside `spend.json` at **un-discounted `us-east-2` AWS list rates** (`infraListCostNanos`):
    * **AWS Lambda (`512 MB` x86_64, `us-east-2`):** `$0.0000083333 / second` (`8,333.33` nanos/ms) + `$0.20 / 1M requests` (`200` nanos/request). *(Example: a 12-second Route Scout streaming turn costs `100,200` nanos = `$0.0001002` in Lambda compute).*
    * **Amazon S3 Standard (`us-east-2`):** `PUT / COPY / POST / LIST` = `$0.005 / 1,000 requests` (`5,000` nanos/call); `GET / SELECT` = `$0.0004 / 1,000 requests` (`400` nanos/call); Storage = `$0.023 / GB-month` (`~21.4` nanos/KB-month). *(Example: 1 `GET` + 1 conditional `PUT` to `spend.json` costs `5,400` nanos = `$0.0000054`).*
    * **Amazon CloudFront (North America/Europe):** `$0.0100 / 10,000 HTTPS requests` (`1,000` nanos/request) + `$0.085 / GB` data transfer out (`~0.08` nanos/byte).
* **Idea 2 — Free Account-Level CloudWatch Usage Snapshot (`./scripts/check_spend.sh --aws-metrics`):**
  * Query `aws cloudwatch get-metric-statistics` (which is **free** within the 1M API request free tier) for `AWS/Lambda` (`Invocations`, `Duration`, `Errors`), `AWS/S3` (`BucketSizeBytes`, `NumberOfObjects` on both `StaticAssetsBucket` and `AppDataBucket`), and `AWS/ECR` / `AWS/Logs` incoming bytes for the current calendar month.
  * Compute both the **Un-Discounted Account AWS Infra List Cost** (what the account would pay with zero AWS Free Tier) and the **Estimated Net Billed AWS Infra Cost** (after deducting AWS Free Tier allowances: `1M` Lambda invocations, `400,000` GB-seconds, `1 TB` CloudFront egress, `500 MB` ECR, `5 GB` CloudWatch Logs).
* **Idea 3 — On-Demand AWS Cost Explorer Invoice Reconciliation (`./scripts/check_spend.sh --aws-bill`):**
  * Because AWS charges **`$0.01` per `aws ce get-cost-and-usage` API call**, Cost Explorer is never polled automatically in background loops. Instead, passing `--aws-bill` to `./scripts/check_spend.sh` executes a single on-demand Cost Explorer query for the current month grouped by `SERVICE` (`Amazon Bedrock`, `AWS Lambda`, `Amazon Simple Storage Service`, `Amazon CloudFront`, `Amazon EC2 Container Registry (ECR)`, `AmazonCloudWatch`, `AWS Key Management Service`, `Tax`) and reconciles the actual AWS invoice against the sum of all `users/*/spend.json` ledgers.
* **Idea 4 — Empirical Phase 2 Break-Even Pricing & Recovery Factor Calculator:**
  * `./scripts/check_spend.sh` outputs a dedicated **Phase 2 Pricing & Break-Even Readiness** section showing:
    1. **Direct Per-User AI + Tool List Cost:** $\sum (\text{Bedrock} + \text{Tools}_{\text{list}})$
    2. **Allocated Per-User AWS Infra List Cost:** $\sum (\text{Lambda} + \text{S3} + \text{CloudFront})_{\text{allocated}}$
    3. **Unallocated Shared AWS Account Overhead:** $\text{ECR} + \text{CloudWatch} + \text{Static SPA} + \text{Proxy Lambda}$
    4. **Empirical Infrastructure Overhead Ratio:** $\frac{\text{Allocated Infra} + \text{Unallocated Overhead}}{\text{Direct AI + Tool List Cost}}$
    5. **Minimum Break-Even Recovery Multiplier (Before & After Stripe `2.9% + $0.30` Fees):** Exact multiplier needed in Phase 2 M5 so that charging users $\text{Direct Cost} \times \text{Recovery Factor}$ covers 100% of AI, external tools, Lambda compute, S3, CloudFront, ECR, CloudWatch, and payment processing with zero net loss.

### Explicit Non-Goals (Out of Scope for M4.5)
* Multi-user Stripe Checkout, payment webhooks, prepaid credit wallets, or `HTTP 402` request blocking (remains deferred to Phase 2 M5).
* Web Studio React UI components, modals, or header badges for spend display.
* Tracking free public API calls (`router.project-osrm.org`, `nominatim.openstreetmap.org`, or direct `read_url_content` HTML fetches) as dollar costs.

### 2.1 Type Definitions & `AiHarnessAdapter` Spend Seam (`route-builder/server/types/spend.ts`, `route-builder/server/types/ai.ts`, `route-builder/server/services/aiService.ts`)

**Architectural Rule — Provider-Agnostic AI Spend via the `AiHarnessAdapter` Seam:**
The application (`AiService`, `ScoutService`, `SpendLedgerService`, and route handlers) must **never** hardcode Bedrock-specific pricing lookups outside the adapter seam. Instead, `AiHarnessAdapter` (`server/services/aiService.ts`) requires explicit spend-reporting methods on the interface itself so that **any** AI backend implementation (`AwsBedrockHarnessAdapter`, test harnesses, or future provider adapters) is forced by TypeScript to expose its model pricing and calculate per-call AI spend:

```typescript
export interface AiHarnessAdapter {
  readonly id: string;
  readonly name: string;
  isAvailable(apiKey?: string): Promise<boolean>;
  generate(prompt: string, options?: GenerateOptions): Promise<string>;
  validateModelId(modelId: string, role?: 'scout' | 'copywriter'): Promise<string>;
  getAvailableModels(): Promise<AiModelOption[]>;
  getModelCatalog(): {
    models: AiModelOption[];
    defaultScoutModelId: string;
    defaultCopywriterModelId: string;
  };
  /**
   * Required Spend Seam #1: Returns the adapter's verified token pricing rate for `modelId`,
   * or `undefined` if the model has no verified pricing entry in this provider.
   */
  getModelPricing(modelId: string): ModelPricingRate | undefined;
  /**
   * Required Spend Seam #2: Deterministically prices a single model call in integer nanodollars
   * and USD for this provider. Must fail closed (throw `UnpricedModelError`) if `modelId`
   * lacks verified pricing.
   */
  calculateCallSpend(usage: ModelCallUsage): PricedModelCallUsage;
  decorateScoutPrompt(domainPrompt: string): string;
  sanitizeResponse(rawText: string): string;
  generateStreamWithTools?(
    prompt: string,
    tools: ToolDeclaration[],
    dispatcher: (name: string, args: Record<string, unknown>) => Promise<unknown>,
    onChunk: (event: ScoutStreamEvent) => void,
    options?: GenerateOptions
  ): Promise<GenerateStreamWithToolsResult>;
}
```

Every `AiHarnessAdapter` implementation must invoke `options?.onUsage?.(this.calculateCallSpend(rawUsage))` inside `generate()` and `generateStreamWithTools()` immediately after each provider call completes. This guarantees that `AiService`, `ScoutService`, and `SpendLedgerService` receive already-priced `PricedModelCallUsage` records through the adapter seam regardless of which AI backend is active.

### 2.2 Verified `us-east-2` Pricing Catalog & Integer Nanodollar Math (`route-builder/server/services/spendPricingCatalog.ts`)

Create [`route-builder/server/services/spendPricingCatalog.ts`](../../../../route-builder/server/services/spendPricingCatalog.ts) containing the authoritative `us-east-2` pricing catalog verified against the AWS Price List API on `2026-10-28`:

1. **Integer Nanodollar Constants & Conversion Helpers:**
   * `export const NANOS_PER_USD = 1_000_000_000;`
   * `export const PRICING_CATALOG_VERSION = '2026-10-28-us-east-2-v1';`
   * `export const GOOGLE_PLACES_ENTERPRISE_CALL_COST_NANOS = 35_000_000;` (`$0.035` per call = `$35.00 / 1,000` calls for Text Search Enterprise SKU triggered by `places.regularOpeningHours` in `GOOGLE_PLACES_FIELD_MASK`).
   * `export const BRAVE_WEB_SEARCH_CALL_COST_NANOS = 5_000_000;` (`$0.005` per call = `$5.00 / 1,000` queries).
   * `export const DEFAULT_GOOGLE_PLACES_MONTHLY_FREE_CALLS = 1000;` (overridable via `process.env.GOOGLE_PLACES_FREE_MONTHLY_CALLS`).
   * `export const DEFAULT_BRAVE_SEARCH_MONTHLY_FREE_CALLS = 0;` (overridable via `process.env.BRAVE_SEARCH_FREE_MONTHLY_CALLS`).
   * `export const DEFAULT_INFRA_BUFFER_MARKUP_PERCENT = 20;` (proactive infrastructure reserve buffer markup percentage, overridable at any time via `process.env.INFRA_BUFFER_MARKUP_PERCENT`).
   * **AWS `us-east-2` Infrastructure List-Rate Constants (Unmasked by AWS Free Tier for Phase 2 Unit Economics):**
     * `export const LAMBDA_512MB_NANOS_PER_MS = 8.333333333;` (`$0.0000166667 / GB-second` × `0.5 GB` = `$0.0000083333 / second` = `8.333333` nanodollars per ms of execution).
     * `export const LAMBDA_REQUEST_COST_NANOS = 200;` (`$0.20 / 1,000,000` requests = `200` nanodollars per invocation).
     * `export const S3_PUT_COPY_POST_LIST_COST_NANOS = 5_000;` (`$0.005 / 1,000` S3 Standard `PUT`/`COPY`/`POST`/`LIST` requests = `5,000` nanodollars per call).
     * `export const S3_GET_SELECT_COST_NANOS = 400;` (`$0.0004 / 1,000` S3 Standard `GET`/`SELECT` requests = `400` nanodollars per call).
     * `export const S3_STANDARD_STORAGE_NANOS_PER_BYTE_MONTH = 0.021420419;` (`$0.023 / GB-month` = `23,000,000 / 1,073,741,824` nanodollars per byte-month).
     * `export const CLOUDFRONT_HTTPS_REQUEST_COST_NANOS = 1_000;` (`$0.0100 / 10,000` HTTPS requests = `1,000` nanodollars per API request).
     * `export const CLOUDFRONT_EGRESS_NANOS_PER_BYTE = 0.079162418;` (`$0.085 / GB` North America/Europe egress = `85,000,000 / 1,073,741,824` nanodollars per byte).
     * `export function calculateAwsInfraListCostNanos(usage: AwsInfraCallUsage): number`:
       ```typescript
       const lambdaComputeNanos = Math.round(Math.max(0, usage.lambdaDurationMs) * LAMBDA_512MB_NANOS_PER_MS) + LAMBDA_REQUEST_COST_NANOS;
       const s3Nanos = Math.max(0, usage.s3GetCalls) * S3_GET_SELECT_COST_NANOS + Math.max(0, usage.s3PutOrListCalls) * S3_PUT_COPY_POST_LIST_COST_NANOS;
       const cfNanos = CLOUDFRONT_HTTPS_REQUEST_COST_NANOS + Math.round(Math.max(0, usage.egressBytes ?? 0) * CLOUDFRONT_EGRESS_NANOS_PER_BYTE);
       return lambdaComputeNanos + s3Nanos + cfNanos;
       ```

### 2.4 Atomic Spend Ledger Service (`route-builder/server/services/spendLedgerService.ts`)

Create [`route-builder/server/services/spendLedgerService.ts`](../../../../route-builder/server/services/spendLedgerService.ts) following the exact dual-mode storage architecture of [`itineraryStorageService.ts`](../../../../route-builder/server/services/itineraryStorageService.ts) ([ADR-0003](../../decisions/0003-s3-atomic-json-persistence.md), [ADR-0004](../../decisions/0004-hybrid-local-dev-mode.md), [ADR-0008](../../decisions/0008-local-storage-in-process-lock.md)):

1. **Storage Locations:**
   * **Cloud S3 Mode (`process.env.S3_STORAGE_BUCKET` set and non-empty):**
     * S3 Key: `users/${encodeURIComponent(userEmail.trim().toLowerCase())}/spend.json` (or `users/${userEmail.trim().toLowerCase()}/spend.json` matching `ItineraryStorageService.userPrefix(userEmail)` -> `users/${userEmail}/spend.json` so it lives right beside `users/${userEmail}/itineraries/`).
     * **Important:** Match `ItineraryStorageService` key layout: `users/${userEmail}/spend.json` (validating `userEmail` is non-empty and contains no `..` or `/` path traversal segments).
   * **Local Dev Mode (`process.env.S3_STORAGE_BUCKET` unset):**
     * Local path: `<itinerariesDir>/.spend/${sanitizeEmailForFilename(userEmail)}.json` (using atomic temp-file write + `fs.rename`).
2. **Concurrency & Conditional Write Safety:**
   * Use an in-process `KeyedMutex` keyed by normalized `userEmail` so concurrent turns from the same user within the same Node/Lambda execution environment serialize cleanly in FIFO order.
   * In S3 mode, `recordTurnSpend(input: RecordTurnSpendInput)` reads the current `spend.json` and its `ETag`, computes the updated `UserSpendLedger`, and writes back with:
     * `IfMatch: etag` when updating an existing object, or
     * `IfNoneMatch: '*'` when creating the user's first `spend.json`.
   * If S3 returns `PreconditionFailed` (`HTTP 412`), retry the read-modify-write cycle up to `MAX_CONDITIONAL_WRITE_RETRIES = 5` times with short jittered backoff (`25ms * attempt`).
3. **Monthly Free-Tier & Rollup Calculation Rules:**
   * Determine `monthKey = timestamp.slice(0, 7)` (`YYYY-MM` UTC) and `dayKey = timestamp.slice(0, 10)` (`YYYY-MM-DD` UTC).
   * Look up prior cumulative calls in `ledger.byMonth[monthKey]`:
     * `priorPlacesCalls = ledger.byMonth[monthKey]?.googlePlacesCalls ?? 0`
     * `priorBraveCalls = ledger.byMonth[monthKey]?.braveSearchCalls ?? 0`
   * For a turn with `newPlacesCalls`, `newBraveCalls`, and `infraUsage`:
     * `billablePlacesCalls = Math.max(0, (priorPlacesCalls + newPlacesCalls) - Math.max(priorPlacesCalls, freeTierConfig.googlePlacesMonthlyFreeCalls))`
     * `billableBraveCalls = Math.max(0, (priorBraveCalls + newBraveCalls) - Math.max(priorBraveCalls, freeTierConfig.braveSearchMonthlyFreeCalls))`
     * `toolListCostNanos = newPlacesCalls * GOOGLE_PLACES_ENTERPRISE_CALL_COST_NANOS + newBraveCalls * BRAVE_WEB_SEARCH_CALL_COST_NANOS`
     * `toolBilledCostNanos = billablePlacesCalls * GOOGLE_PLACES_ENTERPRISE_CALL_COST_NANOS + billableBraveCalls * BRAVE_WEB_SEARCH_CALL_COST_NANOS`
     * `infraUsageResolved: AwsInfraCallUsage = { lambdaDurationMs: Math.max(0, Math.round(input.infraUsage?.lambdaDurationMs ?? 0)), s3GetCalls: Math.max(1, input.infraUsage?.s3GetCalls ?? 1), s3PutOrListCalls: Math.max(1, input.infraUsage?.s3PutOrListCalls ?? 1), egressBytes: Math.max(0, input.infraUsage?.egressBytes ?? 0) }` *(defaults include the `1 GET + 1 PUT` required to read and update `spend.json` itself)*.
     * `infraListCostNanos = calculateAwsInfraListCostNanos(infraUsageResolved)`
     * `totalBilledCostNanos = bedrockCostNanos + toolBilledCostNanos`
     * `totalListCostNanos = bedrockCostNanos + toolListCostNanos`
     * `fullUnitListCostNanos = bedrockCostNanos + toolListCostNanos + infraListCostNanos`
     * `infraBufferReserveNanos = Math.round(fullUnitListCostNanos * (ledger.infraBufferMarkupPercent / 100))`
     * `bufferedUserChargeNanos = fullUnitListCostNanos + infraBufferReserveNanos`
   * Update `totals`, `byMonth[monthKey]`, `byDay[dayKey]`, `byModel[call.modelId]`, and `byOperation[input.operation]` using integer nanodollar addition, then derive all `*Usd` fields via `nanosToUsd(...)`.
   * Prepend the new `SpendTurnEntry` to `recentEntries` and cap `recentEntries` at `MAX_RECENT_ENTRIES = 200`.
   * If `input.modelCalls.length === 0 && input.toolCalls.length === 0 && input.operation !== 'itinerary_storage'` (e.g., an AI request failed input validation before touching Bedrock or any external tool), `recordTurnSpend` is a no-op and returns `null` without writing to S3/disk.

   * Operation type: `'scout_chat'`.
   * Collect every `onUsage` event (across all tool-call loop iterations and any single-turn fallback), every `onToolUsage` event (`resolve_and_standardize_place` and `search_web`), wall-clock `lambdaDurationMs`, and streamed SSE/JSON response `egressBytes`.
   * In the route/service `finally` block (waiting for `spendLedgerService.recordTurnSpend(...)` before completing the request lifecycle, and logging any ledger write failure without masking the primary route response), flush the turn record with `status: 'success' | 'error' | 'aborted'`.

### 2.6 On-Demand Spend Inspection & AWS Account Reconciliation (`GET /api/spend` & `./scripts/check_spend.sh`)

1. **Authenticated API Endpoint (`route-builder/server/routes/spend.ts` registered in `server/app.ts`):**
   * `GET /api/spend`:
     * Protected by `authGuard` (`401` if unauthenticated, `403` if not in `ALLOWED_EMAILS`).
     * Calls `spendLedgerService.getUserSpend(request.authUser.email)` and returns `200 OK` with the `UserSpendLedger` JSON (returning a clean, zeroed `UserSpendLedger` structure if the user has no recorded spend yet).
2. **CLI Inspection & Account Reconciliation Script (`scripts/check_spend.sh` & `route-builder/package.json` `"spend"` script):**
   * Executable bash script `./scripts/check_spend.sh` supporting:
     * **Default (Cloud S3 Per-User Ledger Mode):** Resolves `AppDataBucketName` from CloudFormation stack `RoadtripCopilotCloudStack` in `us-east-2` (or `S3_STORAGE_BUCKET` env var) and user email from `--email <email>`, `SPEND_USER_EMAIL`, or `/roadtrip-copilot/allowed-emails` SSM parameter (first allowlisted email), downloads `s3://<bucket>/users/<email>/spend.json`, and renders a clear terminal table:
       * **Overall Lifetime Spend:**
         * Direct Billed Cost (`$X.XXXXXX` — Bedrock + Free-Tier-Adjusted Tools)
         * Direct List Cost (`$X.XXXXXX` — Bedrock + Unadjusted Tools)
         * Allocated AWS Infra List Cost (`$X.XXXXXX` — Lambda `durationMs` + S3 `GET`/`PUT` + CloudFront at `us-east-2` list rates)
         * **Full Marginal Unit List Cost (`$X.XXXXXX` — Bedrock + Tools List + Allocated AWS Infra List)**
         * Total Turns (`success` / `error` / `aborted`), Total Tokens (`input`, `output`, `cacheRead`, `cacheWrite`), Total Lambda Compute Time (`s`), Total S3 Calls (`GET` / `PUT`).
       * **Current Month (`YYYY-MM`) Spend & Free-Tier Quota:** Monthly Billed vs. Full Unit List Cost, Google Places calls (`X / 1,000 free`), Brave Search calls.
       * **Breakdown by Model:** Model ID, calls, tokens, and USD cost.
       * **Breakdown by Operation:** `scout_chat`, `copilot_alert`, `copilot_batch_alerts`, `copilot_day_title`.
       * **Recent Turns (Last 10):** Timestamp, operation, status, model(s), tokens, tool calls, Lambda ms, and turn cost.
     * **`--aws-metrics` (Free Account-Level CloudWatch & S3/ECR Infrastructure Snapshot):**
       * Queries free AWS CloudWatch/S3/ECR APIs for the current calendar month:
         * `AWS/Lambda` (`Invocations` and total `Duration` across all routes including OSRM/Nominatim proxies and cold starts).
         * `s3 ls --summarize` on `StaticAssetsBucket` and `AppDataBucket` (total object count and storage bytes).
         * `aws ecr describe-images` on the Lambda container repository (total image storage bytes vs. 500 MB free tier).
         * `aws logs describe-log-groups` for `/aws/lambda/...` stored bytes vs. 5 GB free tier.
       * Displays **Account-Level Shared AWS Infrastructure Cost (List Rate vs. Free-Tier Net Billed)** and computes the **Phase 2 Break-Even Recovery Multiplier** ($\frac{\text{Full Account Cost}}{\text{Direct User AI+Tool Cost}}$, both before and after Stripe `2.9% + $0.30` top-up processing fees).
     * **`--aws-bill` (Opt-In AWS Cost Explorer Invoice Reconciliation — `$0.01/call` AWS fee noted in help text):**
       * Calls `aws ce get-cost-and-usage` for the current month (`UNBLENDED_COST` and `NET_UNBLENDED_COST` grouped by `SERVICE`) to display the exact AWS invoice line items side-by-side against `spend.json` totals and calculate the empirical variance and break-even multiplier.
     * **`--local`:** Reads local dev spend file(s) from `route-builder/itineraries/.spend/*.json`.
     * **`--json`:** Outputs the raw `spend.json` document for piping to `jq`.
